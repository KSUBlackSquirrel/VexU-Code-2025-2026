did you try running pros t in the pros integrated terminal while keeping the controller to your computer?
regarding controller prints not working:
the controller is a bit of silly guy.
essentially a message is only sent to the controller every 50ms or so.
these messages can either be vibrations or display commands.
If you try to send a message when you already have one queued, that new message will be discarded, in favor of the queued message.
